# The Practice — Therapy & Wellness Website

A standalone, pixel-perfect clone and replication of [The Practice](https://thepractice.framer.website/).

## Features
- **100% Localized Assets**: All web fonts (`.woff2`), high-res photography, SVG icons, and looping video backgrounds (`.mp4`) are stored locally in `assets/`.
- **Runtime Decoupling**: Free of external Framer hydration runtimes, telemetry, or third-party trackers.
- **Fast Static Architecture**: Pure HTML5/CSS3 with native interactive JavaScript engine (`assets/js/main.js`) powering:
  - Interactive FAQ accordions with comprehensive answers
  - Responsive mobile navigation drawer
  - Smooth anchor link scrolling
- **Hostinger LiteSpeed Optimized**: Clean URLs (`/about`, `/therapists/maya-alvarez`), HTTPS redirection, GZIP/Brotli compression, and immutable cache rules in `.htaccess`.
- **SEO & Discoverability**: Full XML sitemap (`sitemap.xml`), `robots.txt`, and structured metadata.
